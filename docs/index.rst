megalibpy documentation
=======================

``megalibpy`` reads, inspects, and edits MEGAlib/Cosima ``.source`` files from
Python. Use it to inspect simulation parameters, change a source's Galactic
coordinates or flux, and save the updated configuration for Cosima. The
current parser supports one run with one source per file.

The online documentation follows the latest successfully checked ``develop``
branch. Changes on unmerged feature branches are not published to the main
site. The Cosima guide describes execution features separately from the
source-file configuration classes.

The source code is available on `GitHub <https://github.com/Yong2Sheng/megalibpy>`_.
